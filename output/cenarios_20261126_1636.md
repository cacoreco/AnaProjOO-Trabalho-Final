## Conceitual
**Pergunta:** Explique o que é o padrão Memento e qual problema ele resolve.

**Resposta (286s):**

O padrão Memento resolve o problema de capturar e salvar o estado interno de um objeto para poder restaurá-lo posteriormente, mantendo o encapsulamento. A ideia é criar um mementos que guardam snapshots do estado sem violar o encapsulamento.

Os três participantes, no exemplo do Editor com desfazer:
- **Originator (Editor):** tem acesso total ao próprio estado. Cria o Memento com um snapshot desse estado e o usa para restaurá-lo. É o ÚNICO que lê o conteúdo do Memento.
- **Memento (EstadoEditor):** guarda o snapshot do estado. Tem interface estreita (narrow) para o Caretaker, que é VAZIA (sem métodos para ler, salvar ou restaurar), e interface larga (wide) para o Originator. Salvar e restaurar são métodos do Originator, não do Memento.
- **Caretaker (Historico):** guarda e devolve mementos (por exemplo, uma pilha de undo). NUNCA lê nem altera o conteúdo do Memento.

## Exemplo
**Pergunta:** Dê um exemplo de aplicação do padrão Memento em Java.

**Resposta (40s):**

Este exemplo mostra como o Editor salva e recupera seu estado, mantendo a integridade do encapsulamento.

No exemplo, Editor = Originator, EstadoEditor = Memento e Historico = Caretaker.

```java
public class Editor {
    private String texto = "";
    public void escrever(String s) { texto += s; }
    public Memento salvar() { return new EstadoEditor(texto); }       // cria o snapshot
    public void restaurar(Memento m) { texto = ((EstadoEditor) m).texto; }  // só o Editor abre o Memento
    public interface Memento { }                                      // interface VAZIA: é o que o Caretaker enxerga
    private static class EstadoEditor implements Memento {           // o Memento de verdade, escondido
        private final String texto;
        private EstadoEditor(String texto) { this.texto = texto; }
    }
}
class Historico {                                                     // Caretaker: só guarda e devolve
    private final Deque<Editor.Memento> estados = new ArrayDeque<>();
    public void guardar(Editor.Memento m) { estados.push(m); }
    public Editor.Memento recuperar() { return estados.pop(); }
}

// Uso:
historico.guardar(editor.salvar());
editor.escrever("Olá");
editor.restaurar(historico.recuperar());
```

## Conceitos equivocados
**Pergunta:** Com qual padrão o Memento é mais confundido? Explique a diferença entre eles e por que essa confusão acontece.

**Resposta (35s):**

O Memento é confundido principalmente com o Command padrão. Diferente do Command que guarda uma operação e sua inversa (um método), o Memento guarda apenas um estado interno de um objeto para restaurar depois. A confusão acontece porque ambos servem para desfazer ações, mas os métodos são diferentes: Command precisa saber a reversão da operação, enquanto Memento só armazena e restaura estados.
