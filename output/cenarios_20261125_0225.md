## Conceitual
**Pergunta:** Explique o que é o padrão Memento e qual problema ele resolve.

**Resposta (163s):**

O padrão Memento resolve o problema de capturar e salvar o estado interno de um objeto para poder restaurá-lo posteriormente, preservando o encapsulamento. Participantes são Originator (tem acesso total ao seu próprio estado), Memento (guarda snapshot do estado) e Caretaker (salva/restaura mementos). Evitar quando muito memória é necessária ou quando basta uma operação inversa simples. Exemplo em Editor: salvar, restaurar estados sem violar encapsulamento.

## Exemplo
**Pergunta:** Dê um exemplo de aplicação do padrão Memento em Java.

**Resposta (48s):**

O Historico é um objeto que guarda e recupera os mementos.

No exemplo, Editor = Originator, EstadoEditor = Memento e Historico = Caretaker.

```java
public class Editor {
    private String texto = "";
    public void escrever(String s) { texto += s; }
    public Memento salvar() { return new EstadoEditor(texto); }       // cria o snapshot
    public void restaurar(Memento m) { texto = ((EstadoEditor) m).texto; }  // só o Editor abre o Memento
    public interface Memento { }                                      // interface VAZIA: é o que o Caretaker enxerga
    private static class EstadoEditor implements Memento {           // o Memento de verdade, escondido
        private final String texto;
        private EstadoEditor(String texto) { this.texto = texto; }
    }
}
class Historico {                                                     // Caretaker: só guarda e devolve
    private final Deque<Editor.Memento> estados = new ArrayDeque<>();
    public void guardar(Editor.Memento m) { estados.push(m); }
    public Editor.Memento recuperar() { return estados.pop(); }
}

// Uso:
historico.guardar(editor.salvar());
editor.escrever("Olá");
editor.restaurar(historico.recuperar());
```
